# ExoHabitAI

## Project Description

ExoHabitAI is an AI-based system that predicts the habitability potential of exoplanets using planetary and stellar parameters.

## Tech Stack

- Python
- Machine Learning
- Flask
- HTML, CSS, JavaScript
- Data Visualization

## Project Status

Phase 0 - Project Initialization Completed

## Project Structure

- `data/raw/` stores raw datasets and source data.
- `data/processed/` stores cleaned and transformed data prepared for analysis.
- `notebooks/` contains exploratory analysis and experiment notebooks.
- `models/` stores machine learning model artifacts when they are created.
- `backend/` contains server-side application and API code.
- `frontend/` contains the user-facing web interface.
- `dashboard/` contains data visualization and monitoring views.
- `deployment/` contains deployment configuration and related files.
